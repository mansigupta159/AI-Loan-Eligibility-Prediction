# AI-Based Loan Eligibility Prediction

## Project Overview
This project uses machine learning to predict loan eligibility categories from sample applicant financial data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- Google Colab

## Project Features
- Create a synthetic loan application dataset
- Prepare and preprocess data
- Train a machine learning model
- Evaluate model performance
- Predict categories for new applicants
- Save the trained model

## How to Run
1. Open the notebook in Google Colab.
2. Execute the code cells in order.
3. Review the model evaluation results.
4. Enter applicant details to test predictions.

## Dataset
This project uses synthetic data with labels generated by predefined rules for learning purposes.

## Limitations
This is an educational prototype, not a real bank loan approval system. Predictions should not be used for actual lending decisions.
